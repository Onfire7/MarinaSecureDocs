Vehicle Detail

Everything about one vehicle — description, plate number, owners in succession order, and its current location.

Purpose

Reached from Vehicle list, Location detail (a site's current vehicle), or a Ticket/Incident/Note pointing at it. Mirrors Boat detail structurally — a Vehicle is an attachment target like a Boat, per Data Model.

Data shown

FieldSourceNotes
DescriptionVehicle.description
Plate numberVehicle.plate_numberNullable; shown plainly when absent.
OwnersVehicle.owners (ordered)Requires view_owner for names; view_contact additionally for phone/email. Order shown explicitly as succession — who to contact first. Optional: the section is absent when no owners are recorded, identical to lacking the permission.
Current locationVehicle.current_locationLinks to Location detail; nullable.
Notes, incidents, ticketsattached_to = this VehicleSame gating as everywhere else these appear (incidents require view_incidents; tickets and notes unrestricted).

Actions

ActionGatingBehavior
Edit vehicle detailsedit_owner_contactSame permission as vehicle creation on Vehicle list.
Reassign current locationedit_owner_contactUpdates Vehicle.current_location; the move is preserved via the Activity Log rather than a location-history table, matching boats.
Add a noteUnrestrictedOpens New note dialog, pre-attached to this Vehicle.
Log an incidentcreate_incidentsOpens New incident form, pre-attached.
Create a ticketUnrestrictedOpens New ticket form, pre-attached.

States & edge cases

  • No view_owner, or no owners recorded — the owners section is omitted either way; the UI doesn't distinguish "unknown owner" from "you can't see it."
  • No current location — shown as an explicit "unassigned" state rather than an empty field, matching Boat detail.
  • Only a plate, or only a description — either alone is a valid record; a guard noting "trailer, no plate, by the fuel dock" is exactly the kind of partial information this entity exists to hold.

Mobile vs. desktop

Mobile: sections stack vertically, collapsible. Desktop: sections visible together in a wider layout, matching Boat detail and Location detail.
